# МТС — «Технологии, которые держат связь»

Скролл-лендинг с бесконечным зумом по семи локациям (базовая станция → аэростат → исследовательский центр → дата-центр → офис → город → квартира) и обычной страницей «Больше о МТС» + футер.

Стек тот же, что у референса thorgal.com, но без 3D:

| Слой | Что используется |
| --- | --- |
| Фреймворк | Astro 7, статическая сборка, Tailwind 4 |
| Скролл | Lenis (плавный скролл, прогресс сцены считается из него) |
| Графика | OGL (WebGL2): каждый слой — текстурированный квад, 2D-камера, дефокус через mip-bias, premultiplied alpha |
| Анимации DOM | GSAP (скраб-таймлайн заголовков и плашек, интро) |
| Картинки | WebP, генерируются из исходников скриптом на sharp |

## Запуск

```bash
npm install
npm run images   # assets-src/**.png → public/img/*.webp (+ манифест)
npm run dev
npm run build && npm run preview
```

## Макеты

| Что | Где | Фрейм |
| --- | --- | --- |
| Локации 01–03, десктоп | Figma `AGJMz0OKAVwgcjI1P4bYWG`, узел `1:2743`, кадры 22–37 | 1920×1080 |
| Локации 01–03, мобильная раскадровка | тот же файл, секция Mobile `1:917`, кадры 01–21 | 393×852 |
| Локации 04–07, «Больше о МТС», футер | прежний макет `FbvQun8wmNjJR5kvzsfckn` | 1479×832 |

Раскадровка выбирается при загрузке: до 767 px ширины — мобильная, иначе десктопная (на 768–1023 px она идёт с компактной вёрсткой: заголовок внизу, плашки чипсами). При переходе через границу страница перезагружается. Локации 04–07 в обеих раскадровках сняты с прежнего макета: пропорции фрейма те же, поэтому координаты переносятся одним множителем (`legacyRect`), а номера кадров — сдвигом (`legacyFrame`).

## Как устроена сцена

- `src/lib/timeline.ts` — таймлайн в «кадрах» раскадровки и выбор раскадровки (`VARIANT`). Каждый кадр имеет вес (заголовочные держатся дольше), ключи любых треков задаются по кадрам, семплируются по прогрессу скролла `t ∈ [0,1]`. Десктоп: кадры 0…15 = кадры Figma 22…37, дальше 16…38 = кадры 18…40 прежнего макета. Мобильный: 0…20 = кадры 01…21, дальше 21…43.
- `src/lib/scenes.ts` — описание локаций: слои, треки камеры, альфа, затемнение, размытие. Координаты — в системе фрейма сцены (1920×1080, у мобильных сцен `ref: 393×645` — кадр без статус-бара и панели браузера).
  - `space: 'scene'` — слой живёт в пространстве локации, камера его зумит.
  - `space: 'screen'` — слой задан в координатах экрана (как узел в кадре Figma) и не зависит от камеры. Так ведём аэростат, который перелетает между локациями, и все мобильные слои: там каждый слой масштабируется по-своему.
  - `depth` — параллакс (0 фон, 1 ближний план, отрицательный — «за окном»).
  - `blur` — mip-уровни, `alpha`, `rotate`.
- `src/lib/webgl/Stage.ts` — рендер. Один шейдер, один квад, `mesh.draw()` на слой.
- `src/lib/overlay.ts` — DOM поверх WebGL: заголовки, плашки с выносками, волны у антенны. Позиции в координатах макета, вписанного в экран по cover — те же, что у screen-слоёв. В мобильной раскадровке на каждую плашку свой кадр, а её выноска считается на лету до точки сцены.
- `src/lib/bokeh.ts` — красные огни перехода в дата-центр (2D-канвас).
- `src/lib/content.ts` — тексты и раскладка плашек. Переносы строк (`\n`) в заголовках, абзацах и плашках повторяют макет: на десктопе строки не переносятся (`white-space: nowrap`), на мобильных текст течёт сам. Выноска плашки — сторона, точка выхода, длина и поворот (`side`, `at`, `len`, `turn`).

Ключи камеры сняты с геометрии фонов в кадрах Figma по формуле `cam = (tx − bx/s, ty − by/s, 1920/s, 1080/s)`, где `(bx, by, bw)` — узел фона в кадре, `(tx, ty, tw)` — он же в кадре-заголовке, `s = bw / tw`.

### Отладка в dev

В dev-режиме доступно `window.__app`:

```js
__app.goto(6.3)         // плавно доскроллить к кадру
__app.renderAt(15.3)    // синхронно отрисовать кадр (для скриншотов)
document.getElementById('debug').classList.remove('hidden') // t / кадр / размер
```

## Картинки

`npm run images` жмёт исходники из `assets-src/` в WebP по карте `MAP` в `scripts/build-images.mjs` и удаляет из `public/img` файлы слоёв, которых в карте больше нет.

Слои локаций 01–03 лежат в `assets-src/v3/`. Часть из них готовит `python3 scripts/bake-figma.py` (нужны numpy и Pillow) из выгрузок Figma в `assets-src/v3/raw/`. Отдельный шаг нужен потому, что MCP отдаёт три вида картинок и ни один не годится как есть:

- исходник заливки — полный размер и альфа, но без цветокоррекции и кропа, заданных в Figma;
- заливка из `get_design_context` — с цветокоррекцией и кропом, но ужатая до 1024 px;
- рендер узла — точный цвет, но прозрачность залита фоном `#faf4f0`, а узел обрезан кадром.

Поэтому для вырезок (крыша, дальний план, аэростат, модель) цветокоррекция снимается с пары «исходник → эталон» и переносится на полный исходник, непрозрачные фоны (небо 01, лаборатория) берутся рендером узла, а небо 02 собирается из исходника с градиентом hard-light по геометрии кадра-заголовка. Аэростат в макете растянут и скошен (`rotate 8° · scaleY 0.99 · skewX 8°`) — это запекается в текстуру, в сцене он обычный прямоугольник.

## Слои от иллюстратора

Требования те же, что в `материалы-для-локаций.md`: фон отдельным слоем с дорисовкой за объектами, объекты — вырезанные с альфой, исходники 3500–4000 px, пары «широкий/крупный план» с одного ракурса.

Чтобы добавить слой:

1. Положить PNG в `assets-src/`, добавить строку в `MAP` в `scripts/build-images.mjs`, выполнить `npm run images`.
2. В `src/lib/scenes.ts` добавить `{ id, img, space, rect, depth, blur }` в нужную локацию. Для объектов из PSD/Figma достаточно взять координаты узла в кадре-заголовке.
3. Если объект должен «переезжать» между локациями — задать `rect` как список ключей по кадрам.

## Шрифты

В макете MTS Wide (Medium, Bold) и MTS Text (Regular). Лежат в `public/fonts/` как WOFF2 (сконвертированы из TTF через fontTools), подключены в `src/styles/global.css` и предзагружаются в `src/layouts/Base.astro`. MTS Text Medium не передавался — Regular закрывает веса 400–500.

## Что сделано кодом, а не графикой

Волны вокруг антенны, боке-точки дата-центра, плашки и выноски, затемнения и дефокус, зерно. Аэростат в 02 → 03 подменяется своей моделью корпус в корпус: боксы обоих слоёв подогнаны по силуэту. Переход 4 → 5 — чистый зум: в логотип на куртке техника и обратно из логотипа на стене офиса, без накладного логотипа.

## Деплой (mts.my-site.space)

Продакшен — статическая сборка за nginx в docker compose на сервере (Traefik выдаёт HTTPS через Let's Encrypt). Сборка делается локально, на сервер уезжает только `dist/`:

```bash
./deploy/deploy.sh
```

Скрипт собирает проект, синхронизирует `dist/`, `deploy/Dockerfile` и `deploy/nginx.conf` в `/srv/app/mts` и пересобирает сервис `mts` в `/srv/app/docker-compose.yml`.
