# МТС — «Технологии, которые держат связь»

Скролл-лендинг с бесконечным зумом по семи локациям (базовая станция → аэростат → исследовательский центр → дата-центр → офис → город → квартира) и обычной страницей «Больше о МТС» + футер.

Стек тот же, что у референса thorgal.com, но без 3D:

| Слой | Что используется |
| --- | --- |
| Фреймворк | Astro 7, статическая сборка, Tailwind 4 |
| Скролл | Lenis (плавный скролл, прогресс сцены считается из него) |
| Графика | OGL (WebGL2): каждый слой — текстурированный квад, 2D-камера, дефокус через mip-bias, premultiplied alpha |
| Анимации DOM | GSAP (скраб-таймлайн заголовков и плашек, интро) |
| Картинки | WebP, генерируются из исходников скриптом на sharp |

## Запуск

```bash
npm install
npm run images   # assets-src/*.png → public/img/*.webp (+ манифест)
npm run dev
npm run build && npm run preview
```

## Как устроена сцена

- `src/lib/timeline.ts` — таймлайн в «кадрах» Figma (0…40). Каждый кадр имеет вес (заголовочные держатся дольше), ключи любых треков задаются по кадрам, семплируются по прогрессу скролла `t ∈ [0,1]`.
- `src/lib/scenes.ts` — описание локаций: слои, треки камеры, альфа, затемнение, размытие. Координаты — в системе фрейма Figma 1479×832.
  - `space: 'scene'` — слой живёт в пространстве локации, камера его зумит.
  - `space: 'screen'` — слой задан в координатах экрана (как узел в кадре Figma) и не зависит от камеры. Так ведём аэростат, который перелетает между локациями, и передние планы с DOF.
  - `depth` — параллакс (0 фон, 1 ближний план, отрицательный — «за окном»).
  - `blur` — mip-уровни, `alpha`, `rotate`.
- `src/lib/webgl/Stage.ts` — рендер. Один шейдер, один квад, `mesh.draw()` на слой.
- `src/lib/overlay.ts` — DOM поверх WebGL: заголовки, плашки с выносками, волны у антенны, логотип при зуме, подсказка скролла. Позиции в координатах макета, вписанного в экран по cover — те же, что у screen-слоёв.
- `src/lib/bokeh.ts` — красные огни дата-центра (2D-канвас), координаты из кадров Figma.
- `src/lib/content.ts` — тексты и раскладка плашек.

Ключи камеры сняты с геометрии фонов в кадрах Figma по формуле `cam = (tx − bx/s, ty − by/s, 1479/s, 832/s)`, где `(bx, by, bw)` — узел фона в кадре, `s = bw / tw`.

### Отладка в dev

В dev-режиме доступно `window.__app`:

```js
__app.goto(24.5)        // плавно доскроллить к кадру
__app.renderAt(37.3)    // синхронно отрисовать кадр (для скриншотов)
document.getElementById('debug').classList.remove('hidden') // t / кадр / размер
```

## Слои от иллюстратора

Требования те же, что в `материалы-для-локаций.md`: фон отдельным слоем с дорисовкой за объектами, объекты — вырезанные с альфой, исходники 3500–4000 px, пары «широкий/крупный план» с одного ракурса.

Чтобы добавить слой:

1. Положить PNG в `assets-src/`, добавить строку в `MAP` в `scripts/build-images.mjs`, выполнить `npm run images`.
2. В `src/lib/scenes.ts` добавить `{ id, img, space, rect, depth, blur }` в нужную локацию. Для объектов из PSD/Figma достаточно взять координаты узла в кадре-заголовке.
3. Если объект должен «переезжать» между локациями — задать `rect` как список ключей по кадрам.

Важно: экспорт узлов из Figma через MCP заливает прозрачность цветом фона, поэтому для вырезок берутся исходные файлы (rawImages), а не рендер узла.

## Шрифты

В макете MTS Wide и MTS Text. Файлов в проекте нет, подключение уже прописано в `src/styles/global.css`: положите `MTSWide-Medium.woff2`, `MTSWide-Bold.woff2`, `MTSText-Regular.woff2`, `MTSText-Medium.woff2` в `public/fonts/`. До этого работает fallback (Inter / системный).

## Что сделано кодом, а не графикой

Волны вокруг антенны, тросы аэростата, боке-точки дата-центра, плашки и выноски, логотип при зуме на куртку/стену, затемнения и дефокус, зерно.

## Деплой (mts.my-site.space)

Продакшен — статическая сборка за nginx в docker compose на сервере (Traefik выдаёт HTTPS через Let's Encrypt). Сборка делается локально, на сервер уезжает только `dist/`:

```bash
./deploy/deploy.sh
```

Скрипт собирает проект, синхронизирует `dist/`, `deploy/Dockerfile` и `deploy/nginx.conf` в `/srv/app/mts` и пересобирает сервис `mts` в `/srv/app/docker-compose.yml`.
